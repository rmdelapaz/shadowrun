How it works. A sheet auto-saves in this browser once it has a street name. Renaming a sheet renames its save. Use the tabs to move between the three pages. Print prints all three pages of the current runner, one per US Letter sheet, and Print Blank prints an empty set. Export downloads every sheet as a JSON file and Import merges a file like that back in (a sheet with the same street name is replaced). Nothing leaves your browser.

Worked out for you. Physical limit is [(STR × 2) + BOD + REA] ÷ 3, Mental [(LOG × 2) + INT + WIL] ÷ 3 and Social [(CHA × 2) + WIL + Essence] ÷ 3, each rounded up. Initiative is REA + INT + 1D6, astral INT × 2 + 2D6 and AR Matrix REA + INT + 1D6. Composure is CHA + WIL, Judge Intentions CHA + INT, Memory LOG + WIL and Lift/Carry BOD + STR; you walk AGI × 2 and run AGI × 4 metres. The Physical monitor has 8 + half BOD boxes and the Stun monitor 8 + half WIL (rounded up), with BOD boxes of overflow. Essence is 6 minus your augmentations. A skill's dice pool is its rating + linked attribute (add +2 for a specialization). Knowledge skills use LOG (academic, professional) or INT (street, interests, languages).
